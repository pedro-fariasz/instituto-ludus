Política de Privacidade

Trabalho acadêmico. Instituto fictício. Esta política existe apenas para fins da Atividade A3 de Marketing de Conteúdo (Anhembi Morumbi) e descreve, de forma simplificada, como os dados preenchidos no formulário do site seriam tratados.

Quais dados coletamos

  • Nome completo, e-mail e, opcionalmente, WhatsApp;
  • Como você conheceu o Instituto Ludus;
  • Respostas específicas do perfil escolhido (jovem, doador ou empresa);
  • No caso de jovens menores de 18 anos, os dados de um responsável.

Para que usamos

Os dados são usados exclusivamente para enviar o kit em PDF correspondente ao perfil escolhido e para eventual contato sobre o programa, a doação ou a parceria. Nenhuma doação é cobrada automaticamente a partir deste formulário.

Com quem compartilhamos

Os dados ficam armazenados em uma planilha Google de uso interno do grupo responsável pelo trabalho acadêmico e não são vendidos, compartilhados ou usados para qualquer outra finalidade.

Seus direitos (LGPD)

Você pode pedir a exclusão dos seus dados a qualquer momento, bastando enviar essa solicitação para o e-mail de contato do grupo responsável pelo trabalho.

Contato

Por ser um trabalho acadêmico, este site não representa uma organização real. Dúvidas sobre o uso dos dados neste exercício podem ser direcionadas ao professor responsável pela disciplina ou ao grupo autor do trabalho.
